Shape Manager

Description:
Shape Manager is a Java Swing application designed to manage and visualize 3D shapes used in game engines. The system allows users to define shapes by specifying their color, dimensions (diameter/side), and coordinates in 3D space (x, y, z). Key features include:

1. Shape Creation and Management: Abstract Shape class supports different shape types, with each shape automatically assigned a unique ID and customizable properties like color and size.<br>
2. Dynamic Calculations: Each shape can calculate its size based on its dimensions, enabling accurate management of game engine assets.<br>
3. Visual and Functional Interface: Leveraging Java Swing for an intuitive GUI to create, modify, and display the details of shapes.

Shape Manager is a robust tool for developers managing complex game engine assets with precision and ease.
